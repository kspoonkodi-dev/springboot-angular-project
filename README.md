# 📚 Online Learning Platform

## 📌 Project Overview
Developed a full-stack application using Spring Boot and Angular following MVC architecture and REST API design, ensuring seamless frontend-backend integration.

This platform allows users to register, browse courses, and access tutorials efficiently.

---

## 🚀 Features
- 👤 User Registration & Login  
- 📖 Course Management  
- 🎥 Tutorial Management  
- 🔍 Course Browsing  

---

## 🛠️ Tech Stack
- Backend: Spring Boot (Java)  
- Frontend: Angular  
- Database: MySQL  
- API: REST APIs  

---

## 📂 Modules
- User Module  
- Course Module  
- Tutorial Module  

---

## 🎯 Key Highlights
- Built RESTful APIs for backend services  
- Integrated Angular frontend with Spring Boot backend  
- Followed MVC architecture  
- Implemented clean and modular code structure
