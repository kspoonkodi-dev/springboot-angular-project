# 🎯 Angular Frontend – CRUD Application

## 📌 Overview

This is the frontend of a full-stack CRUD application built using **Angular**.
It interacts with a backend (Spring Boot) via REST APIs to perform Create, Read, Update, and Delete operations.

---

## 🚀 Features

* 📋 View all records
* ➕ Add new data
* ✏️ Edit existing data
* ❌ Delete records
* 🔄 Real-time UI updates
* 🌐 REST API integration

---

## 🛠️ Tech Stack

* Angular
* TypeScript
* HTML / CSS
* RxJS
* Angular CLI

## ▶️ Run the Project

### 1️⃣ Install dependencies

```
npm install
```

### 2️⃣ Start development server

```
ng serve
```

### 3️⃣ Open in browser

```
http://localhost:4200/
```

---

## 🔗 Backend API

This frontend connects to a Spring Boot backend API.

Make sure backend is running before starting frontend.
